VESSEL Sovereign Server Microkernel

Universal Minecraft Server Loader hợp nhất 6 hệ sinh thái (Fabric, Quilt, Forge, NeoForge, Bukkit/Spigot, Paper/Folia) trong 1 tệp server.jar duy nhất — Khởi động 1 lần duy nhất, tự động tải Minecraft bản mới nhất, tích hợp sẵn GeyserMC & spark, và tự động cập nhật mỗi 1 tiếng.

Release: VESSEL-2.3.0-rev1046 Java 21 LTS + Vector SIMD Single-Pass Boot (0 Restart) Built-in GeyserMC & spark Hourly Zero-Lag Auto-Update

1. Khởi Chạy Nhanh Chỉ Với 1 Lần Duy Nhất (Single-Pass First-Run Boot)

Khác với các server truyền thống bắt buộc phải chạy lần 1 để sinh file rồi tắt đi bật lại, VESSEL hoàn tất toàn bộ 16 bước khởi động chỉ trong 1 lần chạy duy nhất kể cả ở lần chạy đầu tiên: 

# 1. Chạy mặc định (Tự động lấy Minecraft release mới nhất, tích hợp Geyser + Spark, nạp mọi mod/plugin):
java -jar server.jar --nogui

# 2. Chạy chế độ Tối Ưu Tối Đa (Bật toàn bộ SIMD Physics, Zero-Copy Netty, AI LOD, Zstd RAM Cache, LazyDFU):
java -jar server.jar --vessel-ultra-optimize --nogui

# 3. Chạy chế độ Debug Sâu (Trace chi tiết Bytecode Rewriting, ClassLoader, Event Bus & Registry Audit):
java -jar server.jar --vessel-deep-debug --nogui

(hoặc --vessel-max-perf)		 false Bộ Flag Tối Ưu Hết Cỡ: Kích hoạt đồng thời 6 hệ thống tối ưu cấp nhân: --vessel-simd-physics, --vessel-zero-copy-netty, --vessel-aggressive-ai-lod, --vessel-zstd-ram-cache, --vessel-lockless-strands, và --vessel-lazy-dfu-noisium cùng 40 bộ điều phối Super-Mod.
--vessel-deep-debug
(hoặc --vessel-debug-all)		 false Flag Debug Sâu VESSEL: Kích hoạt toàn bộ chẩn đoán sâu gồm --vessel-trace-bytecode, --vessel-trace-classloader, --vessel-trace-events, --vessel-trace-registry, và --vessel-profile-boot để admin/dev theo dõi từng bước dịch bytecode và nạp mod/plugin.
--vessel-single-pass-boot true Hoàn tất khởi tạo thư mục, chấp nhận EULA, tải Mojang bundler, nạp mod/plugin và mở server ngay trong 1 lần khởi chạy duy nhất mà không cần khởi động lại.
--vessel-universal-compat true Bật động cơ nâng cấp bytecode đa thế hệ trong RAM, cho phép các mod và plugin viết cho bản Minecraft thấp hơn chạy mượt trên bản Minecraft mới nhất.
--vessel-auto-latest true Tự động truy vấn Mojang Piston Meta API (version_manifest_v2.json) để luôn chạy phiên bản Minecraft chính thức mới nhất (latest.release).
--vessel-version=<ver> latest.release Ghim cứng một phiên bản Minecraft cụ thể (ví dụ --vessel-version=1.21.4) nếu admin muốn cố định phiên bản server.

3. Quy Tắc Tương Thích Mod/Plugin Đa Thế Hệ & Chặn Mod Bản Cao Hơn Server

Tương thích ngược tự động (modMcVersion <= serverMcVersion): Khi server chạy phiên bản Minecraft mới nhất (hoặc cao hơn bản của mod/plugin), LiveJarBytecodeTransformingClassLoader sẽ tự động nâng cấp bytecode trong RAM (ví dụ: đổi constructor new ResourceLocation(...) sang ResourceLocation.fromNamespaceAndPath(...), đổi field Entity.level sang method Entity.level(), nâng INVOKEVIRTUAL InventoryView của Bukkit cũ lên INVOKEINTERFACE cho 1.21+, và nâng schema DataPack loot_tables/ → loot_table/).
Từ chối thẳng nếu Server chạy bản thấp hơn Mod (modMcVersion > serverMcVersion): Nếu server đang chạy phiên bản Minecraft thấp hơn phiên bản mà mod/plugin yêu cầu (ví dụ server chạy 1.20.1 nhưng bỏ mod yêu cầu 1.21.4 vào), ForwardVersionModRejectionGuard sẽ từ chối load thẳng mod/plugin đó ngay lập tức và hiển thị thông báo rõ ràng:
"Yêu cầu cài đặt bản thấp hơn của mod/plugin hỗ trợ phiên bản server hiện tại, hoặc nâng cấp server lên phiên bản Minecraft cao hơn (--vessel-version=<ver> hoặc mặc định latest.release)."

4. Auto-Update Từ GitHub Mỗi 1 Tiếng (Không Lag, Staged Patches, Bảo Vệ 100% Dữ Liệu User)

  • Quét tự động mỗi 1 tiếng (3600s): HourlyGitHubAutoUpdateDaemon chạy trên một Daemon Thread có độ ưu tiên thấp tách biệt hoàn toàn khỏi Main Tick Thread (0.00 ms lag).
  • Chuỗi mã định danh VesselBuildVersionCode: Có định dạng VESSEL-<semver>-rev<build>+mc<mcVer>-geyser<geyserVer>-spark<sparkVer>. VESSEL giải mã chuỗi này để biết chính xác bản hiện tại đang thấp hơn (<), bằng (== bản mới nhất), hay cao hơn (>) bản trên GitHub.
  • Cập nhật ngay khi đang chạy & Apply Patches khi Restart: Khi phát hiện bản mới hơn trên GitHub, VESSEL tải gói cập nhật về vùng đệm cache/updates/staged/ đồng thời cập nhật ngay phiên bản Geyser, Spark và Minecraft latest.release mới nhất mà không làm gián đoạn server đang chạy. Các bản vá nhân (kernel patches) sẽ tự động được áp dụng (apply) ngay ở giây đầu tiên khi admin restart server.
  • Bảo vệ 100% dữ liệu người dùng (UserDataPreservationSnapshotGuard): Mọi thư mục và tệp riêng của user gồm mods/, plugins/, config/, vessel.yml, server.properties, eula.txt, world/ được khóa bảo vệ bằng chữ ký SHA-256 — không bao giờ bị xóa hay ghi đè khi auto-update.
